# План реализации минимального AI Gate

## Цель

Собрать минимальное анонимное AI-микроприложение: React-интерфейс, Node.js API, PostgreSQL, cookie-сессия, локальный кэш истории и сохранение сообщений в БД.

## Этапы

1. Подготовить монорепозиторий с `client`, `server`, Docker Compose и примером переменных окружения.
2. Реализовать анонимную сессию через `httpOnly` cookie с UUID.
3. Реализовать PostgreSQL-таблицу `messages` и автоматическую инициализацию схемы.
4. Добавить API:
   - `GET /api/session` — создать/вернуть сессию;
   - `GET /api/history` — получить историю текущей сессии;
   - `POST /api/chat` — сохранить запрос, вызвать AI и сохранить ответ.
5. Реализовать React-интерфейс: история, поле запроса, состояние загрузки и ошибки.
6. Добавить `localStorage` как быстрый локальный кэш, синхронизируемый с БД.
7. Проверить установку зависимостей, сборку клиента и серверные тесты.
8. Описать запуск и короткий сценарий скринкаста в README.

## Критерий готовности

- `docker compose up -d db` запускает PostgreSQL.
- `npm install` и `npm run dev` запускают клиент и API.
- Первый запрос создаёт cookie-сессию.
- Сообщения появляются в интерфейсе, localStorage и PostgreSQL.
- После перезагрузки история восстанавливается и синхронизируется с сервером.
